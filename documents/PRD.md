# Document 01 - PRD

## App Name
Xtin Capital

## Tagline
To make wealthy not rich

## Problem
Indian retail investors juggle fragmented tools to trade, learn, and get advice, which slows decision-making and creates inconsistent outcomes. They need one trusted platform that unifies investing, learning, and expert guidance.

## Target User
A 22-40 year old Indian retail investor who is serious about building long-term wealth but lacks a single reliable hub. They want actionable insights, trusted advice, and practical learning without switching apps.

## Core Features (Must Have)
- Algorithms: AI-powered trading strategies for modern markets
- Calculators: SIP, FD, tax, and 19+ financial calculators
- Learn: Free courses on trading and finance
- Fundamental: Company research, statements, watchlists, and AI reports
- Mutual Funds: Advisor and investor dashboards for portfolios
- Journal: Daily market insights and analysis
- Advisory: Connect with SEBI-registered experts
- Newsletter: Weekly market updates and insights

## User Stories
- As an investor, I want to access AI trading strategies so that I can make better decisions faster.
- As a learner, I want structured finance courses so that I can build confidence in investing.
- As a mutual fund investor, I want a portfolio dashboard so that I can track performance in one place.
- As a user, I want daily market insights so that I can stay informed without digging across sources.
- As a user, I want access to SEBI-registered advisors so that I can get trusted guidance.
